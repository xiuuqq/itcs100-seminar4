Нүүр Бидний тухай

Нүүр хуудас

Энэхүү вэб сайт нь ITCS100 хичээлийн 4-р семинарын хүрээнд статик вэб хуудас хэрхэн бүтэцлэгдэж, сүлжээгээр дамжин хэрэглэгчийн дэлгэцэд хүрэхийг харуулах зорилготой.

Вэб хуудас ачаалах үндсэн үе шат

  • Домэйн нэрийг DNS-ээр IP хаяг руу хөрвүүлэх.
  • Сервер рүү HTTP/HTTPS хүсэлт илгээж хариу хүлээн авах.
  • HTML, CSS болон зургийг уншиж дэлгэцэд дүрслэх.

Багийн мэдээлэл болон дэлгэрэнгүй танилцуулгыг Бидний тухай хуудаснаас үзнэ үү.
